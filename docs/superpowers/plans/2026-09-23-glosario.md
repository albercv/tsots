# Glosario de términos para la transcripción — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que el usuario mantenga desde la app una lista de términos propios (marcas, productos, jerga) para que Whisper los escriba bien en subtítulos y caption. Ejemplo real: "Claude Code" se transcribe como "Cloud Code".

**Evidencia (2026-09-23, vídeo `yahoo_limpio.mp4`, 98 s, mlx-whisper turbo):**

| Prompt inicial | "Claude" | "Cloud" |
|---|---|---|
| ninguno | 0 | 4 |
| `Claude Code, Claude, Anthropic, Yahoo.` | 4 | 0 |

**Architecture:** Dos defensas complementarias, ambas alimentadas por el mismo glosario:

1. **Antes de transcribir:** los términos correctos se pasan a Whisper como `initial_prompt`. Corrige la mayoría de casos sin saber cómo se equivoca el modelo.
2. **Después de transcribir:** un diccionario de correcciones (`variante → término`) sustituye errores conocidos en la lista de `Palabra`, conservando los tiempos. Cubre lo que el prompt no alcanza: vídeos largos (Whisper solo ve los últimos 224 tokens de contexto, y el prompt puede salir de la ventana) y errores persistentes.

Además, los términos se añaden al prompt del caption SEO para que el LLM respete su ortografía y los use en hashtags.

Lógica nueva en `videopipeline/glosario.py` (pura, sin dependencias). El pipeline la aplica una sola vez tras transcribir, así subtítulos y caption usan el mismo texto corregido. GUI: botón **Términos…** en el grupo Subtítulos, con un diálogo de texto como el de Marca.

**Tech Stack:** Python 3.11, PySide6 6.11, mlx-whisper 0.4.3 / faster-whisper 1.2.1 (`initial_prompt` en ambos), pytest + pytest-qt. Sin dependencias nuevas.

## Formato del glosario

Texto libre, una entrada por línea. A la izquierda la forma correcta; a la derecha, opcional, las variantes erróneas separadas por comas:

```
# Líneas con # son comentarios
Claude Code = Cloud Code, Claus Code
Anthropic
Evolve2Digital = evolve to digital, evolve 2 digital
TSOTS
```

- Todas las formas correctas van al prompt de Whisper y al del caption.
- Las variantes se buscan sin distinguir mayúsculas ni tildes, como palabras completas, incluso repartidas en varias `Palabra` ("Cloud" + "Code.").
- Una línea sin `=` solo alimenta el prompt.

**Decisión tomada sin consultar (revisable):** un único glosario por usuario, guardado en `QSettings` como la marca. Se descartó un glosario por proyecto o por vídeo hasta que haga falta.

## Global Constraints

- El glosario **nunca** hace fallar el vídeo. Un glosario vacío o mal escrito equivale a no tenerlo.
- Prompt de Whisper como máximo `MAX_CHARS_PROMPT = 600` caracteres (≈ 200 tokens, bajo el límite de 224). Si se supera, se recortan términos del final y el diálogo lo avisa.
- Las correcciones conservan `inicio` del primer token sustituido y `fin` del último. Si cambia el número de palabras, el tramo se reparte a partes iguales.
- La puntuación pegada al último token se conserva ("Code." → "Code.").
- Tests: `QT_QPA_PLATFORM=offscreen .venv-clearvoice/bin/python -m pytest -m "not lenta" -q` en verde tras cada tarea.
- GUI, comentarios y nombres de código en español. Commits en inglés, sin trailer `Co-Authored-By` (preferencia del usuario en este repo).
- Rama `feature/glosario` desde `develop`; merge `--no-ff` al terminar.

## Riesgos

- **Prompt demasiado largo:** Whisper puede devolver texto truncado o vacío. Mitigado con `MAX_CHARS_PROMPT` y aviso en el diálogo.
- **Prompt que "contagia" estilo:** Whisper imita la puntuación y mayúsculas del prompt. Se usa una lista simple terminada en punto, que en la prueba real no alteró el resto del texto.
- **Falsos positivos en correcciones:** una variante común ("code") podría sustituir palabras legítimas. Solo se corrigen coincidencias de palabras completas y el diálogo muestra las correcciones activas.

## Resultado (2026-09-23)

Implementado en `feature/glosario`. Verificación real con mlx-whisper turbo:

| Vídeo | Glosario | "Claude" | "Cloud" |
|---|---|---|---|

| Dos vídeos unidos, 371 s, tramo final | ninguno | 0 | 4 |
| ídem | solo pista (`Claude Code`) | 0 | 4 |
| ídem | pista + correcciones | 3 | 1 |

Confirma el riesgo previsto: en vídeos largos la pista sola no llega al
final y las correcciones son las que funcionan. La mención restante es
"Cloud" suelto ("usamos Cloud para desarrollar"); se cubre añadiendo
`Claude = Cloud`, a costa de cambiar también "cloud" con sentido de nube.
El caption generado con `gemma4:26b` puso `#claudecode` como primer hashtag.
